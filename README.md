### Hi, I'm Clément 👋

**Independent software engineer**, server side: architecture, backends, APIs, tooling. Fourteen years of engineering, ten of them independent, with **Rust** as my language of choice and a strong affinity for email, contacts and calendars.

- 🦀 **Rust**: new projects, audits and rescue of existing code
- 📬 **PIM integration** (email, contacts, calendars): Gmail, Microsoft 365 and standard servers, with the provider quirks already known
- 🔧 **Maintenance**: what I build keeps working, year after year
- 🤖 **AI** is part of how I work: RAG, MCP servers, tool calling, agents

### Open source: [Pimalaya](https://pimalaya.org)

<a href="https://pimalaya.org"><img src="https://soywod.me/pimalaya.svg" alt="" width="40" height="40" align="left" /></a>
